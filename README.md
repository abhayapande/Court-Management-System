# Court Management System

## 1. Project Description

The Court Management System is a Database Management System (DBMS) project aimed at organizing and managing court-related information efficiently. The proposed system will maintain records of cases, clients, lawyers, judges, court hearings, and case status in a structured database.

The project aims to improve data organization, simplify case record retrieval, and reduce the difficulties associated with manual record management.

## 2. Project Objectives

- Store and manage court case records.
- Maintain client, lawyer, and judge information.
- Organize court hearing dates and case details.
- Track the status of cases.
- Apply DBMS concepts such as tables, primary keys, foreign keys, relationships, and SQL queries.
