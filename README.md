# CourtEase – Court Management System

## 1. Project Description

CourtEase is a Court Management System developed to organize and manage court-related information efficiently.

The system aims to maintain records of cases, clients, lawyers, judges, hearing dates and case statuses using a structured database.

It helps improve data organization, simplifies record retrieval and reduces the difficulties associated with manual record management.

## 2. Objectives

- To maintain court case records systematically.
- To manage client, lawyer and judge information.
- To track hearing dates and case status.
- To improve data organization and retrieval.
- To reduce manual paperwork.

## 3. Technologies Used

- Frontend: HTML and CSS
- Backend: Python
- Database: MySQL
- Query Language: SQL
